Browsteer

Claude Code can now work in this browser, once you hand it this key

The key names this browser. Claude Code can only reach it through a bridge running on this computer, and only after you paste the key into a session.

Checking the bridge…

Set it up

  1. Add the bridge to Claude Code

    Run this once in a terminal, from the folder where you cloned Browsteer. It needs Bun 1.3 or newer.

    bun install && claude mcp add -s user browsteer -- bun run "$(pwd)/bridge/mcp.ts"

  2. Start Claude Code

    The bridge starts with the first session and keeps running. The lamp above turns green when this browser has found it; there is nothing to click here.

  3. Give Claude the key and a task

    Paste this into Claude Code and finish the sentence. You can get it again any time from the Browsteer button in the toolbar.

    /browse bst-····-···· summarise the page I have open

What it can see, and where that goes

While paired, Claude Code can read and operate any normal web page in this browser, using the sessions you are signed in to. Treat the key like access to this browser profile.

Page contentSent only to the bridge at 127.0.0.1:8787 on this computer, and only when Claude Code asks for it. The extension itself contacts no server.
ClaudeWhat the bridge returns becomes part of your Claude Code conversation, under the same terms as anything else you show Claude.
Semantic targetingOff unless you turn it on in the bridge. When on, an outline of the current page goes to TypeSafe to locate controls by description.
Request logThe address, method and submitted form data of the last 300 requests pages made are kept in memory, so Claude can find a page's own API. It is never written to disk and clears when the browser restarts.
Stored in the browserThe pairing key and the last element you picked. Nothing else.
DialogsA page's alert() boxes are answered automatically and their text is passed to Claude. Confirm and prompt dialogs still wait for you unless Claude was told how to answer.

Where it does not work

Browser pages such as settings and the extension store, and tabs that were already open when the extension was installed. Reload those tabs once.

To stop all access, choose New key in the toolbar popup or disable the extension. To stop the bridge: bun run hub:stop.
