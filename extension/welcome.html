Connect Claude Code

Browsteer needs a small program on this computer, the bridge, to pass Claude's requests to this browser. Paste this into Claude Code and it installs it.

Set up Browsteer for me: clone https://github.com/ovidijusr/browsteer-ext and run bun run setup in it. Install Bun first if it is missing (https://bun.sh).
Or run the commands yourself

In a terminal, with Git and Bun installed:

git clone https://github.com/ovidijusr/browsteer-ext
cd browsteer-ext
bun run setup

Waiting for the bridge. This page moves on by itself.

Troubleshoot setup
  • Bun is missing. Install it from bun.sh, then run bun run setup again in the browsteer-ext folder.
  • Setup stopped with an error. Paste the error into Claude Code and ask it to fix it.
  • Another browser profile. The bridge connects to the profile where you installed this extension; keep this window open.

Allow a site

Open a page you want help with and click the Browsteer button in the toolbar. Then click Allow ‹site› and open for 1 hour. The button shows the site you're on.

No Browsteer button? Click the puzzle-piece icon in the toolbar and pin Browsteer.

Waiting for an allowed site. This page moves on by itself.

Give Claude the key

Paste this into Claude Code, then type what you want done. For example: summarise my open pull requests.

/browse bst-····-····-···· ‹your task›

Treat it like a password: anyone with it can use the sites you allow. New key in the popup replaces it.

Waiting for Claude to pair. This page moves on by itself.

You'll always find the key in the Browsteer popup.

Browsteer is ready

Next time:

Open the page you want help with, click the Browsteer button, allow the site, then paste the /browse line into Claude Code with your task.

Every time, the same three states

  1. LockedUntil you allow a site. Claude can't read or click anything.
  2. Open for an hourOnly on the sites you allowed. Stop now ends it at once.
  3. Locked againBy itself after the hour, with nothing for you to do.
